# C# Data Structures and OOP Studies

## Overview
This repository stores C# study projects focused on Data Structures and
Object-Oriented Programming (OOP). Each folder contains a small, focused
exercise or challenge created while learning and practicing these topics.

## Goals
- Practice core data structure concepts in C#
- Reinforce OOP principles with hands-on examples
- Keep a clean archive of learning projects

## Repository Structure
- `DesafioTuplas001/`, `DesafioTuplas002/`, `DesafioTuplas003/`:
  standalone C# exercises (each folder is its own project)

## Getting Started
Requirements:
- .NET SDK (check with `dotnet --version`)

Run a project:
```bash
cd DesafioTuplas001
dotnet restore
dotnet run
```

## Notes
This is a personal learning repository. Projects are small and may change
as new topics are studied.
